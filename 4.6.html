Studi Kasus Pemrograman Sensor & Display LCD 16x2

Lembar Kerja Studi Kasus Modul 4

Soal & Data Pengamatan Sistem Sensor & LCD

Studi kasus pemanfaatan sensor ultrasonik dan sensor api (flame sensor) dengan antarmuka penampil LCD I2C 16x2 serta indikator LED pada Arduino Uno.

1

Studi Kasus Soal 1: Pembacaan Sensor Ultrasonik pada LCD 16x2

Soal Studi Kasus
Instruksi Soal:

Buatlah program untuk menampilkan hasil pembacaan sensor ultrasonik pada layar LCD 16x2 menggunakan Arduino Uno.

  • Baris 1: Menampilkan teks "Jarak: XX cm", di mana XX adalah nilai jarak yang diukur dalam satuan sentimeter (cm).
  • Baris 2: Menampilkan status berdasarkan jarak: "Dekat" jika jarak kurang dari 10 cm, "Sedang" jika jarak antara 10 cm hingga 50 cm, dan "Jauh" jika jarak lebih dari 50 cm.

Petunjuk Logika Pemrograman Soal 1

Gunakan pengkondisian if-else untuk menentukan status jarak pada baris kedua LCD:

// Logika Status Jarak Ultrasonik
if (jarak < 10) { lcd.print("Dekat"); }
else if (jarak >= 10 && jarak <= 50) { lcd.print("Sedang"); }
else { lcd.print("Jauh"); }
2

Studi Kasus Soal 2: Sistem Deteksi Api (Flame Sensor) & LCD 16x2

Soal Studi Kasus
Instruksi Soal:

Buatlah sistem deteksi api menggunakan sensor flame yang terhubung ke Arduino. Sistem ini harus mampu menampilkan status deteksi api dan kondisi keselamatan pada LCD 16x2 serta mengontrol indikator LED (LED ON ketika ada api dan LED OFF ketika tidak ada api). Ketika api terdeteksi, LCD akan menampilkan peringatan bahaya dan LED menyala. Jika tidak ada api yang terdeteksi, LCD akan menampilkan status "Aman" dan LED mati.

  • Baris 1: Menampilkan teks "Terdeteksi Api" atau "Tidak Terdeteksi Api" sesuai kondisi sensor.
  • Baris 2: Menampilkan teks "Kondisi: Bahaya" ketika api terdeteksi, dan "Kondisi: Aman" ketika tidak ada api.
  • Indikator LED: LED ON (menyala) ketika ada api, dan LED OFF (mati) ketika tidak ada api.

Petunjuk Logika Pemrograman Soal 2

Gunakan fungsi digitalRead() untuk membaca sinyal digital dari sensor api dan digitalWrite() untuk mengontrol LED:

// Logika Sensor Api & Indikator LED (Aktif LOW)
int sensorState = digitalRead(flamePin);
if (sensorState == LOW) {
  // Terdeteksi Api -> LED ON
  digitalWrite(ledPin, HIGH);
} else {
  // Tidak Ada Api -> LED OFF
  digitalWrite(ledPin, LOW);
}
