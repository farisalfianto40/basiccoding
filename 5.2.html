Panduan Penggunaan Simulasi

  1. Rangkai komponen di lab: Potensiometer (Pin A0), Sensor Level Cairan Merah / Water Level Depth Sensor (Pin Analog A1), Relay Pompa (Pin 4), Buzzer (Pin 5), dan Servo Motor Valve (Pin 9).
  2. Unggah sketch program Arduino ke papan Arduino Uno.
  3. Klik tombol "Hubungkan Arduino" di atas dan pilih COM Port yang sesuai.
  4. Putar potensiometer untuk mengubah target volume (% setpoint). Amati garis target pada animasi web menyesuaikan secara langsung.
  5. Saat sensor level merah terendam air dan mencapai target volume, katup servo akan otomatis menutup (0°), relay mematikan pompa, dan buzzer berbunyi menandakan batch dosis selesai.

// =========================================================================
// PROGRAM AUTOMATIC CHEMICAL DOSING & SAFETY SERVO VALVE
// JURUSAN TEKNIK KIMIA INDUSTRI - SMK SMTI YOGYAKARTA
// -------------------------------------------------------------------------
// Pin Analog A0 : Potensiometer 10K (Set-point Target Volume)
// Pin Analog A1 : Sensor Level Cairan Merah (Water Level Depth Sensor)
// Pin Digital 4 : Relay Pompa Pasokan (Pump Relay)
// Pin Digital 5 : Buzzer Alarm Batch Selesai
// Pin Digital 9 : Servo Motor (Safety Shut-off Valve)
// Baud Rate     : 9600 bps
// =========================================================================

#include <Servo.h>

const int POT_PIN = A0;
const int WATER_LEVEL_PIN = A1; // Sensor level analog warna merah
const int RELAY_PUMP_PIN = 4;
const int BUZZER_PIN = 5;
const int SERVO_PIN = 9;

Servo valveServo;

// Nilai kalibrasi pembacaan sensor level merah
const int SENSOR_MIN_VAL = 0;    // Kering (0%)
const int SENSOR_MAX_VAL = 520;  // Terendam penuh (100%) - sesuaikan kalibrasi fisik

void setup() {
  Serial.begin(9600);

  pinMode(RELAY_PUMP_PIN, OUTPUT);
  pinMode(BUZZER_PIN, OUTPUT);

  valveServo.attach(SERVO_PIN);

  // Status awal aman
  digitalWrite(RELAY_PUMP_PIN, LOW);
  digitalWrite(BUZZER_PIN, LOW);
  valveServo.write(0); // Katup tertutup (0 derajat)
}

void loop() {
  // 1. Baca Potensiometer untuk Target Volume Setpoint (10% - 100%)
  int potValue = analogRead(POT_PIN);
  int targetVolume = map(potValue, 0, 1023, 10, 100);

  // 2. Baca Sensor Level Cairan Merah (Analog A1)
  int rawLevel = analogRead(WATER_LEVEL_PIN);
  int currentLevelPct = map(rawLevel, SENSOR_MIN_VAL, SENSOR_MAX_VAL, 0, 100);
  currentLevelPct = constrain(currentLevelPct, 0, 100);

  // 3. Logika Dosing & Interlock Katup
  String status = "";
  int valveAngle = 0;
  int pumpState = 0;

  if (currentLevelPct < targetVolume) {
    // Belum mencapai target: Buka Katup 90 derajat & Nyalakan Pompa
    pumpState = 1;
    valveAngle = 90;
    digitalWrite(RELAY_PUMP_PIN, HIGH);
    valveServo.write(valveAngle);
    digitalWrite(BUZZER_PIN, LOW);
    status = "DOSING";
  } else {
    // Target Terpenuhi: Tutup Katup 0 derajat, Matikan Pompa & Bunyikan Alarm
    pumpState = 0;
    valveAngle = 0;
    digitalWrite(RELAY_PUMP_PIN, LOW);
    valveServo.write(valveAngle);
    digitalWrite(BUZZER_PIN, HIGH);
    status = "COMPLETE";
  }

  // 4. Kirim Data Serial Terformat ke Web Dashboard
  Serial.print("LEVEL:");
  Serial.print(currentLevelPct);
  Serial.print("|TARGET:");
  Serial.print(targetVolume);
  Serial.print("|PUMP:");
  Serial.print(pumpState);
  Serial.print("|VALVE:");
  Serial.print(valveAngle);
  Serial.print("|STATUS:");
  Serial.println(status);

  delay(500);
}
