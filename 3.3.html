SUB 3.3

Potensiometer & Pengendalian Kecerahan PWM

Praktik Analog Input to PWM Output

Kontrol Dimmer LED Manual dengan Potensiometer

Pelajari cara membaca sinyal analog dari Potensiometer menggunakan analogRead(A0) (0–1023) lalu konversi menjadi sinyal PWM analogWrite(3, pwm) (0–255) secara langsung menggunakan fungsi map().

Skema Rangkaian Potensiometer & LED

PIN A0 (Input) & PIN ~3 (PWM)

Visual Hardware

A0 & PIN ~3
ADC: 512 | PWM: 128 (50%)
Putar Potensio: 512 (2.50V)
0 (0V) 512 (2.5V) 1023 (5V)
Program Dimmer LED dengan Fungsi map()

Gunakan fungsi map(val, 0, 1023, 0, 255) untuk mengubah pembacaan sinyal analog 10-bit dari Potensiometer menjadi sinyal PWM 8-bit untuk LED.
