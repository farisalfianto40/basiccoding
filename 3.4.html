3.4

Studi Kasus Pemrograman I/O Analog - Kalibrasi Sensor Level Air

Soal Studi Kasus
Instruksi Soal:

Sebuah tangki penampungan cairan pada proses industri dilengkapi dengan sensor level air analog yang terhubung ke pin A1 Arduino Uno. Pembacaan nilai ADC analog berada pada rentang 0 hingga 1023. Buatlah program untuk membaca sinyal analog sensor tersebut, lalu konversikan menjadi persentase ketinggian air dalam skala 0% hingga 100% menggunakan fungsi map(), dan tampilkan hasilnya pada Serial Monitor.

Tabel Data Pengamatan Hasil Kalibrasi

No Kondisi Tangki / Ketinggian Air Nilai Analog ADC (0–1023) Hasil Pemetaan (0–100%) Status Level Air
1 Tangki Kosong (Min) 0 0% Sangat Rendah / Kosong
2 Ketinggian Rendah 256 25% Rendah
3 Ketinggian Separuh (Half) 512 50% Normal / Sedang
4 Ketinggian Tinggi 768 75% Tinggi
5 Tangki Penuh (Max) 1023 100% Penuh

Petunjuk Pemrograman Arduino

Gunakan fungsi map() dengan rumus sebagai berikut:

// Sintaks Konversi Map (0-1023 ke 0-100%)
int nilaiADC = analogRead(A1);
int persentaseAir = map(nilaiADC, 0, 1023, 0, 100);
