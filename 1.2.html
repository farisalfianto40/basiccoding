Ilustrasi Smart Home Interaktif

1 Ruang Standalone
Atur Suhu Ruangan (Geser ke ≥28°C untuk aktifkan kipas): 25.0 °C
< 28°C (OFF) 28°C - 34.9°C (Sedang) >= 35°C (Kuat)
STATUS: KIPAS OFF
Suhu < 28.0°C. Kipas mati / standby (Blok ELSE aktif).
// Program Smart Home: Kontrol Kipas Otomatis (Arduino IDE)
#define PIN_KIPAS 9
#define PIN_SENSOR A0

void setup() {
pinMode(PIN_KIPAS, OUTPUT);
Serial.begin(9600);
}

void loop() {
float suhu = 25.0;
if (suhu >= 35.0) {
// Suhu Panas: Kipas Nyala Kuat
analogWrite(PIN_KIPAS, 255); // PWM 100%
}
else if (suhu >= 28.0) {
// Suhu Hangat: Kipas Nyala Sedang
analogWrite(PIN_KIPAS, 128); // PWM 50%
}
else {
// Suhu Sejuk / Normal: Kipas Matikan (OFF)
analogWrite(PIN_KIPAS, 0); // PWM 0%
}
}
