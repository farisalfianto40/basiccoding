Studi Kasus - Kalibrasi Sensor Capacitive v1.2 & Kontrol Pompa Air 5V

Soal Studi Kasus
Skenario & Prosedur Praktikum:

Pada sistem pertanian cerdas, digunakan Capacitive Soil Moisture Sensor v1.2 (Warna Hitam) yang terhubung ke pin analog A0. Sensor ini menghasilkan sinyal analog tegangan terbalik: semakin kering media tanah, semakin tinggi nilai ADC yang terbaca.

Langkah Kerjanya:
  1. Kalibrasi Sensor: Catat nilai ADC saat sensor di udara terbuka (adcKering) dan saat sensor dicelupkan ke wadah air (adcBasah). Catat nilai hasil pengamatan ke dalam tabel.
  2. Pemetaan Persentase: Gunakan rumus map(nilaiADC, adcKering, adcBasah, 0, 100) lalu kunci rentangnya menggunakan constrain(persen, 0, 100).
  3. Aktivasi Relay & Indikator LED:
    • Kelembapan < 40% (Kering): Relay Aktif (Pompa Air 5V ON), LED Merah ON, LED Kuning OFF, LED Hijau OFF.
    • Kelembapan 40% – 70% (Lembap Ideal): Relay Nonaktif (Pompa Air 5V OFF), LED Merah OFF, LED Kuning ON, LED Hijau OFF.
    • Kelembapan > 70% (Sangat Basah): Relay Nonaktif (Pompa Air 5V OFF), LED Merah OFF, LED Kuning OFF, LED Hijau ON.

Tabel Pengamatan 1: Hasil Kalibrasi Nilai Analog (ADC)

No Kondisi Pengujian Media Sensor Pembacaan Analog ADC (0–1023) Target Kelembapan (%) Keterangan Kalibrasi
1 Udara Bebas / Pot Kering ... (Isi Nilai ADC) 0 % Batas Maksimal ADC (adcKering)
2 Sensor Terendam Air / Basah ... (Isi Nilai ADC) 100 % Batas Minimal ADC (adcBasah)

Tabel Pengamatan 2: Hasil Pemetaan Persen & Respon Output Sistem

No Kondisi Sampel Nilai Analog (ADC) Hasil Persen (%) Status Relay / Pompa Indikator LED
1 Sangat Kering ... < 40% ON (Pompa Menyala) LED Merah ON
2 Lembap (Ideal) ... 40% - 70% OFF (Mati) LED Kuning ON
3 Sangat Basah ... > 70% OFF (Mati) LED Hijau ON

Petunjuk Pemrograman Arduino C++

Gunakan variabel konstanta kalibrasi hasil praktikum Anda pada fungsi map() dan pembatas constrain():

// 1. Nilai Hasil Kalibrasi Pengamatan Anda
const int adcKering = 820; // Ganti dengan ADC saat udara/tanah kering
const int adcBasah = 380; // Ganti dengan ADC saat sensor terendam air

// 2. Pembacaan ADC dan Konversi ke Persentase
int nilaiADC = analogRead(A0);
int persentase = map(nilaiADC, adcKering, adcBasah, 0, 100);
persentase = constrain(persentase, 0, 100); // Batasi agar tetap 0-100%

// 3. Logika Otomatisasi Pompa & LED Indikator
if (persentase < 40) {
  digitalWrite(pinRelay, LOW); // Pompa ON (Active-LOW)
  digitalWrite(ledMerah, HIGH); // Indikator Kering
  digitalWrite(ledKuning, LOW);
  digitalWrite(ledHijau, LOW);
} else if (persentase <= 70) {
  digitalWrite(pinRelay, HIGH); // Pompa OFF
  digitalWrite(ledMerah, LOW);
  digitalWrite(ledKuning, HIGH); // Indikator Ideal
  digitalWrite(ledHijau, LOW);
} else {
  digitalWrite(pinRelay, HIGH); // Pompa OFF
  digitalWrite(ledMerah, LOW);
  digitalWrite(ledKuning, LOW);
  digitalWrite(ledHijau, HIGH); // Indikator Sangat Basah
}
