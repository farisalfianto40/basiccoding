SUB 4.1

Sensor Suhu & Kelembapan DHT11

Praktik Sensor Digital DHT11

Pengukuran Suhu (°C) & Kelembapan Nisbi (%) Udara

Mempelajari cara menginterfasikan sensor digital DHT11 pada Digital Pin 2 menggunakan library Adafruit DHT. Program membaca data suhu dalam satuan Celcius (°C) dan tingkat kelembapan udara (RH %) secara berkala.

Langkah Instalasi Library DHT11

Wajib Dilakukan
1

Buka Manage Libraries

Klik menu "Sketch" > "Include Library" > "Manage Libraries..." pada Arduino IDE.

2

Cari & Install Library

Ketik "DHT sensor library" pada pencarian, pilih DHT sensor library by Adafruit, lalu klik INSTALL.

Skema Rangkaian DHT11

Data: PIN 2 | VCC: 5V | GND: GND

Visual Sensor

DIGITAL PIN 2
28.0 °C Suhu
65.0 % Kelembapan
Suhu (°C): 28 °C
Kelembapan (%): 65 %
Program Pembacaan Suhu & Kelembapan DHT11

Menggunakan library <DHT.h>, fungsi dht.readTemperature() membaca temperatur dan dht.readHumidity() membaca kelembapan udara.
