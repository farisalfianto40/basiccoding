Panduan Penggunaan Simulasi

  1. Rangkai modul komponen: Sensor Curah Hujan (Pin A0), Sensor LDR (Pin A1), Limit Switch (Pin D2), Buzzer Alarm (Pin D5), dan Servo Motor Terpal (Pin D9)[cite: 7].
  2. Unggah program C++ ke mikrokontroler Arduino Uno.
  3. Klik tombol "Hubungkan Arduino" di atas dan pilih COM Port yang terhubung.
  4. Beri tetesan air pada Sensor Hujan atau tutup Sensor LDR. Amati Servo Motor berputar menutup terpal kanopi hingga menekan Limit Switch[cite: 7].
  5. Ketika Limit Switch tertekan (Active), Buzzer akan berbunyi memberi sinyal peringatan bahwa terpal telah melindungi bahan baku secara sempurna[cite: 7].

stockpile_protection_system.ino 
// =========================================================================
// PROGRAM OUTDOOR STOCKPILE PROTECTION SYSTEM
// INDUSTRI SEMEN, TAMBANG & LOGAM
// -------------------------------------------------------------------------
// Pin Analog A0 : Sensor Curah Hujan (Rain Sensor Module)
// Pin Analog A1 : Sensor LDR (Light Dependent Resistor)
// Pin Digital 2 : Limit Switch (Penanda Terpal Tertutup Rapat)
// Pin Digital 5 : Buzzer Alarm Peringatan Field Personnel
// Pin Digital 9 : Servo Motor (Atap Kanopi / Terpal Pelindung)
// Baud Rate     : 9600 bps
// =========================================================================

#include <Servo.h>

const int RAIN_SENSOR_PIN = A0;
const int LDR_SENSOR_PIN  = A1;
const int LIMIT_SWITCH_PIN = 2;
const int BUZZER_PIN       = 5;
const int SERVO_PIN        = 9;

Servo tarpServo;

void setup() {
  Serial.begin(9600);

  pinMode(LIMIT_SWITCH_PIN, INPUT_PULLUP); // Active LOW saat tertekan
  pinMode(BUZZER_PIN, OUTPUT);

  tarpServo.attach(SERVO_PIN);

  // Kondisi awal (Aman / Cerah): Terpal terbuka (0 derajat)
  tarpServo.write(0);
  digitalWrite(BUZZER_PIN, LOW);
}

void loop() {
  // 1. Pembacaan Sensor Curah Hujan & LDR
  int rawRain = analogRead(RAIN_SENSOR_PIN);
  // Sensor Hujan: Nilai analog rendah melambangkan air/basah
  int rainPct = map(rawRain, 1023, 200, 0, 100);
  rainPct = constrain(rainPct, 0, 100);

  int rawLdr = analogRead(LDR_SENSOR_PIN);
  int lightPct = map(rawLdr, 0, 1023, 0, 100);
  lightPct = constrain(lightPct, 0, 100);

  // 2. Pembacaan Status Limit Switch
  // Limit Switch terhubung ke Pin D2 (INPUT_PULLUP)
  bool isLimitActive = (digitalRead(LIMIT_SWITCH_PIN) == LOW);

  int servoAngle = 0;
  int buzzerState = 0;
  String status = "CLEAR";

  // 3. Logika Proteksi Otomatis Stockpile
  // Hujan terdeteksi (>30%) ATAU Cahaya redup/gelap (<40%)
  if (rainPct > 30 || lightPct < 40) {
    servoAngle = 180; // Putar servo menarik terpal pelindung
    tarpServo.write(servoAngle);
    status = "CLOSING";

    // Jika terpal sudah menarik penuh dan menekan Limit Switch
    if (isLimitActive) {
      digitalWrite(BUZZER_PIN, HIGH); // Bunyikan Buzzer Peringatan
      buzzerState = 1;
      status = "PROTECTED";
    } else {
      digitalWrite(BUZZER_PIN, LOW);
      buzzerState = 0;
    }
  } else {
    // Cuaca cerah: Terpal dibuka kembali
    servoAngle = 0;
    tarpServo.write(servoAngle);
    digitalWrite(BUZZER_PIN, LOW);
    buzzerState = 0;
    status = "OPEN";
  }

  // 4. Kirim Data Telemetry Format Serial ke Web Dashboard
  Serial.print("RAIN:");
  Serial.print(rainPct);
  Serial.print("|LIGHT:");
  Serial.print(lightPct);
  Serial.print("|SERVO:");
  Serial.print(servoAngle);
  Serial.print("|LIMIT:");
  Serial.print(isLimitActive ? 1 : 0);
  Serial.print("|BUZZER:");
  Serial.print(buzzerState);
  Serial.print("|STATUS:");
  Serial.println(status);

  delay(500);
}
